# CLI binary name

The Verona chain CLI is invoked as **`xiond`** in all commands and scripts in this skill.

- Skill id and branding: **Verona** (`verona-bin`)
- Installed binary: **`xiond`** (Cosmos SDK daemon for Verona)
- A future CLI rename may ship under a Verona-branded command; when that happens, update script invocations and examples accordingly. Until then, always use `xiond`.

This skill merged the former separate init, usage, and wasm CLI skills into one in-plugin corpus.
